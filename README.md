Este repositorio reúne la documentación de los retos de seguridad realizados en **OWASP Juice Shop**, con el propósito de comprender las vulnerabilidades, cómo se aprovechan y qué medidas permiten corregirlas o mitigar su impacto.

Cada reto incluye su objetivo, los conceptos necesarios, el procedimiento, las evidencias y una explicación de por qué funciona la técnica utilizada. La intención es ir más allá de reproducir una solución: entender qué ocurre en la aplicación y relacionar los resultados con su causa.

El contenido está pensado como material de estudio personal y como una referencia accesible para quienes estén aprendiendo seguridad web. Las pruebas se realizan en un entorno de laboratorio diseñado para este fin.
